# senac-pti-react-native
Projeto desenvolvido para a disciplina de Programação para Dispositivos Móveis (Produção Textual Individual) do curso de Análise e Desenvolvimento de Sistemas do Senac. Consiste na criação de um componente funcional de Card de Produto para um aplicativo de delivery de Fast Food, utilizando React Native, Expo e boas práticas de componentização.
